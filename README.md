# Supply-Chain-Network-Analysis-using-Graph-Theory-and-GNNs
Graph-based insights for an FMCG Company in Turkey

∗ Implemented Graph Neural Networks on SupplyGraph dataset, a benchmark dataset for an FMCG Company to
detect anomalies, find bottlenecks and efficient/ profitable warehouses (nodes) in Supply Chain.
∗ Applied Graph algorithms like Louvain, Girvan and Centrality measures using NetworkX and Gephi to get inference
and supply chain-based insights.
