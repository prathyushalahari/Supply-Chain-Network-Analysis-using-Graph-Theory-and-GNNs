# Supply-Chain-Network-Analysis-using-Graph-Theory-and-GNNs
Graph-based insights for an FMCG Company in Turkey.

-> Built and deployed Graph Neural Networks on the SupplyGraph dataset to detect anomalies, identify bottlenecks,
and surface efficient/profitable warehouse nodes for supply chain optimization.

-> Implemented GCN for plant efficiency prediction, GAE for new production-link recommendations, and GraphSAGE
for product demand forecasting. also Applied Graph algorithms like Dijkstra’s, Louvain, Girvan-Newman using
NetworkX and Gephi to get inference and supply chain-based insights.
